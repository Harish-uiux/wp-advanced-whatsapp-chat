**A professional, modular WhatsApp Chat Plugin for WordPress with advanced features, admin panel control, and elegant frontend animations.**

## 🌟 Features

- ✅ **Authentic WhatsApp Interface** – Real WhatsApp-like chat experience
- 🎨 **Highly Customizable** – Match your brand with flexible design controls
- 📱 **Responsive Design** – Mobile, tablet & desktop friendly
- 🛠️ **Powerful Admin Panel** – Manage everything from your WordPress dashboard
- 📌 **Multi-position Button** – Bottom-left or bottom-right
- 💬 **Prefilled Message Support** – Set initial text for better engagement
- 🎯 **Smart Display Rules** – Control where & when the chat appears
- ✨ **Smooth Animations** – Premium-feel transitions and effects

## 📦 Installation

### ✅ Automatic Installation (Recommended)

1. Go to your WordPress Dashboard
2. Navigate to `Plugins > Add New`
3. Click `Upload Plugin`
4. Select the `wp-advanced-whatsapp-chat.zip` file
5. Click `Install Now`, then `Activate Plugin`

### 💻 Manual Installation

1. Download and unzip the plugin
2. Upload the folder to `/wp-content/plugins/`
3. Activate the plugin from your dashboard under `Plugins`

---

## ⚙️ Configuration

After activation, find a new menu in your dashboard: `WP WhatsApp`.

### General Settings
- **WhatsApp Number** (e.g. `919876543210`)
- **Display Name**
- **Welcome Message**
- **Pre-filled Message**

### Button Settings
- Button Position: Left or Right
- Icon/Text Layout
- Rounded Corners
- Bubble Text

### Appearance
- Chat Header & Text Colors
- Chat Background or Pattern
- Bubble Color Customization
- Footer Input Field Styling

### Display Rules
- Show/Hide on Mobile/Desktop
- Auto-open Triggers
- Hide After Close (session)
- Profile Image & Designation

## ❓ FAQ

**Q: Does this connect directly to WhatsApp?**  
A: Yes, it uses [Click-to-Chat API](https://wa.me) to open WhatsApp or WhatsApp Web with your number and message.

**Q: Can I use it on mobile sites?**  
A: Absolutely! The widget is fully responsive.

**Q: Will this slow down my website?**  
A: Not at all. It’s optimized and lightweight.
